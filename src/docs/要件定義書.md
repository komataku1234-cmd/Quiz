## 1. 目的・背景

- **このアプリで何を実現するか（1〜2行）**：
　研修（HTML/CSS/JS/TS/React）で学んだ内容をもとにチームで問題を自作し、出題・採点まで行えるクイズアプリを作ることで、自分たちの理解度を「問題そのもの」で証明する。あわせて発表会では他チームと問題を交換し、相互にクイズを解き合えるようにする。

- **想定利用者**：
　同じ研修を受講した他チームのメンバー（発表会でクイズを交換して出題し合う相手）、および自チームメンバー（作問・動作確認を行う）。

## 2. 機能一覧

各機能について「何を」「どう動くか」を自分たちの言葉で記述する（課題の F-1〜F-7 を自分たちの表現で書き直す）。

| ID | 機能名 | 概要 | 備考 |
|---|---|---|---|
| F-1 | 作問フォーム | バリデーションを満たすフォームで問題を追加できる。追加後は登録済み一覧に即時反映（map＋key）|
| F-2 | スタート画面 | 出題カテゴリ（すべて/JS/TS/React）と出題順（登録順／シャッフル）を選んで開始できる|

| F-7 | 状態管理 | クイズ進行の状態遷移を useReducer で管理する（下記 §5-1 の状態機械）。「なぜ useReducer を使うか」を設計書に書くこと |

## 3. 挙動要件（非機能）

課題 §3-1 の T-1〜T-4 について、期待する挙動を具体的に記述する。

| ID | 挙動要件 | 期待する具体的な動き |
|---|---|---|
| T-1 | タイマーのリセット | タイマーは問題が切り替わるたびに制限時間へリセットされること。 |
| T-2 | 回答後の停止 | 回答済み（解説表示中）はカウントダウンが止まること。時間切れ後もマイナスに進まないこと。 |
| T-3 | クリーンアップ | setInterval は必ず useEffect のクリーンアップ関数で解除すること（画面遷移・アンマウント時にタイマーが残らない）。|

## 5. バリデーション仕様

| フィールド | ルール | エラーメッセージ |
|---|---|---|
| 問題文 | 必須／5〜200文字／前後空白を除去（transform） | 問題文は5文字以上で入力してください。 |
| 選択肢1〜4 | 各必須／各60文字以内／独自ルール（test）：4つの選択肢に重複があってはならない | 選択肢が重複しています。 |
| 正解 | 必須／1〜4のいずれか（oneOf） | 正解を選択してください。 |
| 解説 | 必須／10文字以上 | 解説は10文字以上で入力してください。 |
| 制限時間 | 必須／整数／5〜120（秒） | 制限時間は5〜120秒で入力してください。 |
| カテゴリ | 必須／JavaScript・TypeScript・React のいずれか（oneOf） | カテゴリを正しく選択してください。 |

- 使用する transform：（記入：例）問題文フィールドで `.transform(value => value.trim())` を使用し、前後の空白を除去してから文字数チェックを行う。
- 使用する独自 test：（記入：例）選択肢4つに対して `.test('unique-choices', '選択肢が重複しています。', (value, context) => { 選択肢1〜4の値を配列にして重複がないか確認するロジック })` を実装する。
