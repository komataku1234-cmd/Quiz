
### 画面遷移の説明

- アプリ起動後、ユーザーは「作問モード」と「プレイモード」を切り替えられる。
- 作問モードでは問題の登録と一覧確認を行う。
- プレイモードではスタート画面でカテゴリと出題順を選択し、クイズを開始する。
- 問題画面では回答または時間切れ後に解説を表示する。
- 「次の問題」で次の問題へ進み、最後の問題が終了すると結果画面へ遷移する。
- 結果画面の「もう一度」ボタンでスタート画面へ戻り、新しくクイズを開始できる。

### 3-2. State の形

```ts
type QuizState = {
  status: 'idle' | 'playing' | 'answered' | 'finished';
  order: Question[];
  currentIndex: number;
  score: number;
  answers: {
    questionId: string;
    selectedChoiceId: string | null;
    correct: boolean;
  }[];
};
```

### 3-3. Action の一覧

| Action | payload | 何が起きるか（状態の変化） |
| --- | --- | --- |
| START | 出題設定（カテゴリ・出題順） | 出題順を作成し、最初の問題を表示する（playingへ遷移） |
| SELECT | choiceId | 回答を記録し、正誤判定・スコア更新後、answeredへ遷移する |
| TIMEOUT | なし | 時間切れとして不正解を記録し、answeredへ遷移する |
| NEXT | なし | 次の問題へ進む。最後の問題ならfinishedへ遷移する |
| RESTART | なし | スコア・回答履歴・問題番号を初期化し、idleへ戻る |

### 3-4. なぜ useState ではなく useReducer か

（記入：状態遷移に伴って複数の値が同時に変わる／遷移ルールを1か所に集約したい、など自分たちの言葉で）

クイズでは、回答すると「現在の問題番号」「スコア」「回答履歴」「画面状態」が同時に変化します。

これらをそれぞれ useState で管理すると、更新処理が複数箇所に分かれ、状態管理が複雑になります。

そこで useReducer を使用し、状態の更新や画面遷移のルールを Reducer にまとめることで、処理を分かりやすく管理できるようにしました。

ステートが変わることによっての処理が多いから、見やすいようにreducerでまとめてる


## 4. フックの採用理由


| フック | 使用箇所 | 目的・理由 |
| --- | --- | --- |
| useReducer | QuizRunner | クイズの進行状態（開始・回答・時間切れ・終了）を一元管理するため |
| useEffect | Timer | タイマーの開始・停止、setInterval のクリーンアップを行うため |
| useRef | Timer | setInterval のIDを保持し、タイマーを確実に停止するため |
| useState | QuestionForm | 問題文・選択肢・解説などフォームの入力値を管理するため |
| useContext（任意） | 使用しない | 今回のアプリ規模では Props によるデータ受け渡しで十分なため使用しない |


### 4-1. Timer のクリーンアップ設計（T-3）

Timer コンポーネントでは useEffect 内で setInterval を開始する。

useEffect の戻り値（クリーンアップ関数）で clearInterval を実行し、タイマーを解除する。

これにより、

- 問題が切り替わったとき
- 回答したとき
- コンポーネントがアンマウントされたとき

に古いタイマーが残らないようにする。

```ts
useEffect(() => {
  const intervalId = setInterval(() => {
    // カウントダウン処理
  }, 1000);

  return () => {
    clearInterval(intervalId);
  };
}, [currentQuestion, status]);
```

## 5. ロジックの切り出し

判定や集計などの処理は純粋関数として切り出し、コンポーネントとは分離して管理する。

| 関数 | 役割 |
| --- | --- |
| buildOrder(questions, category, shuffle) | カテゴリと出題順（登録順・シャッフル）に応じて出題順を作成する。 |
| shuffleQuestions(questions) | 問題をランダムな順番に並び替える。 |
| judgeAnswer(question, choiceId) | 選択した回答が正解かどうかを判定する。 |
| calcResult(answers) | 正答数・正答率・所要時間を計算する。 |
| getWrongQuestions(questions, answers) | 不正解だった問題だけを抽出し、復習リストを作成する。 |
